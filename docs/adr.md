# 决策记录

- 2026-10-22（Windows 部署）：锁文件首字节只用于系统排他锁，读取持有者从第二字节开始。启动端生成随机会话标识，只通过子进程环境传递，worker 消费后不向后代继续传递；握手结合会话、系统锁与心跳确认实际 worker，不要求虚拟环境启动器 PID 等于 worker PID。
- 2026-10-22（首次设置失败）：保留完整链接会话鉴权。首次读取失败时主卡片展示恢复指引，角色错误提示优先于等待提示；不通过匿名状态接口绕过会话鉴权。读取恢复后清除首次错误。

- 2026-10-22：以 Claude 的像素直播间向导为基线继续。预检、短链解析与扫描共用 SQLite 请求预算；预检失败也持久保存退避，代价是快速完成机器人绑定后可能仍需等待 5 分钟才能建基线。页面显示等待时间，不增加绕过冷却入口。
- 2026-10-22：候选通过验证才提交收藏夹归属，Store 事务在配置写入异常时回滚归属与暂停变化。已有历史/任务禁止换源。首次配置风控恢复由页面显式发起，不请求平台、不解除投递暂停；恢复和配置变更均须取得 worker 锁。

- 2026-10-22：用户澄清 agent 只协助从 GitHub 安装；采用独立 CLI + worker，不引入 MCP、LLM API 或 agent 常驻依赖。初版采用 CLI，后续新增下述本地网页向导。
- 2026-10-22：以 dy 的 experiment/ux-polish 当前工作区为来源，复用官方机器人鉴权、分片上传与一次性群口令绑定；不以主目录 main 的 OneBot 实现替代用户要求。
- 2026-10-22：匿名公开收藏夹作为第一版输入；无 Cookie 收集。代价：不支持私密收藏夹。
- 2026-10-22：首次完整基线不发送历史；BV 永久去重；源快照失败不提交。代价：移除后重新加入仍不重发。
- 2026-10-22：QQ 上传与实际发送分离，发送前持久化状态，缺回执进入 uncertain。代价：可能需要人工核对一次；不承诺跨平台 exactly-once。
- 2026-10-22：默认 15 分钟轮询、每页间隔 3 秒、5 页预算、每轮 1 条投递；失败退避、风控暂停。代价：新增有延迟。
- 2026-10-22：默认拒绝多 P 与超出 30MB 的视频，不暗中降级为链接或文件。代价：长视频和多 P 需要用户选择或后续能力。
- 2026-10-22：agent 与页面共用 Control；日常模式与间隔存 SQLite meta，优先于配置默认值。worker 每 2 秒查看本地控制，当前一条完成后应用模式变化；无需热改文件或重启。代价：模式保存不负责启动系统服务。
- 2026-10-22：首次部署使用四步本地网页向导，静态 HTML/CSS/JS 随 Python wheel 分发，标准库 HTTP 服务只监听 127.0.0.1。无需前端构建器；代价是暂不支持远程浏览器管理。
- 2026-10-22：AppSecret 经本地页面验证后保存到指定系统凭据后端，配置只存随机引用；保留无桌面环境的显式环境变量入口。无明文后备；Linux 需要可用的 Secret Service，跨机器恢复必须重新提供密钥。
- 2026-10-22：设置 API 校验会话令牌、精确 Host/Origin，限制请求体与操作频率；令牌使用 URL fragment 并由浏览器立即移除。静态内容白名单、CSP、禁止缓存与请求日志。后台不接受公网连接。
- 2026-10-22：群绑定与首次历史基线完成后，由用户显式启用转发，默认建议手动模式。agent 通过 setup-status 读取非秘密进度；凭据引用存在只证明已记录，不代替当前系统凭据可读性和平台权限验证。
- 2026-10-22：start 以独立会话启动后台 worker，PID/会话、进程锁和心跳共同确认启动；stop 使用会话专属协作停止标记。关闭终端后继续，暂不自动安装开机服务；下载/上传中的停止需等待当前一条结束。
- 2026-10-22：显式 sync 独立于自动模式，只扫描一次并冻结待发集合；并发请求在事务内合并。手动请求最短源冷却 5 分钟，保留失败退避；本次队列投递默认间隔 10 秒。自动模式保留每轮发送额度。代价：冷却和长视频可使一次手动任务持续较久。
- 2026-10-22：控制状态使用已有 schema v1 的 meta 扩展，不新增业务表；升级沿用旧去重记录。回滚旧版前停止全部 worker 并备份 SQLite，新控制功能无法由旧版执行，不在旧版上继续依赖手动模式设置。

- 2026-10-22：应用户要求，将上述旧版 5 分钟最短轮询/手动源冷却替换为 10 秒，最大仍为 24 小时、默认仍为 15 分钟。秒为内部统一单位，页面支持数值与单位，CLI/API 兼容整数分钟并增加整数秒；只换模式不改间隔。首次预检到基线也使用 10 秒共享下限。缩短正常周期不缩短失败退避：源失败基数至少 300 秒、首次至少 600 秒，调度异常至少 300 秒，保留风控暂停。代价：10 秒全列表轮询增加平台请求量，尚未做真实平台高频验证；不承诺准时送达，不并发补跑。
