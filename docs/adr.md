# 决策记录

每条写“决定”和“代价”。改动这些行为前先读对应条目。

## 形态与边界
- 独立 CLI + 后台 worker；agent 只负责帮用户从 GitHub 安装和日常下指令，运行时不依赖 MCP、LLM API 或常驻 agent。
- 第一版输入是匿名公开收藏夹，不收集 Cookie。代价：不支持私密收藏夹。
- QQ 侧复用官方机器人鉴权、分片上传与一次性群口令绑定（改编自 dy-archive，见 THIRD_PARTY_LICENSES.md），不用 OneBot。
- 默认单用户自部署；不把本地无鉴权模型扩展成公网服务。

## 投递语义
- 首次完整基线不发送历史；BV 永久去重；源快照失败不提交。代价：移除后重新加入仍不重发。
- QQ 上传与实际发送分离，发送前持久化状态，缺回执进入 uncertain。代价：偶尔需要人工核对一次；不承诺跨平台 exactly-once。
- 默认拒绝多 P 与超出 30MB 的视频，不暗中降级为链接或文件。代价：长视频和多 P 暂不支持。
- 只把 QQ 数字码 40034105（群内未开主动发言）映射为明确拒绝：任务 failed 并暂停。5xx、未知错误、超时与无回执保留 uncertain。平台码在 targets 层映射，core 只认通用的“明确拒绝 / 结果不明”。

## 节奏与退避
- 默认 15 分钟轮询，范围 10 秒～24 小时；每页间隔 3 秒，分页预算按收藏夹数量自动设置（最多 50 页），超过 1000 条拒绝。
- 缩短正常周期不缩短失败退避：源失败基数至少 300 秒、首次至少 600 秒，指数递增，上限一天；风控暂停需人工恢复。代价：10 秒轮询会增加平台请求量，不承诺准时送达，不并发补跑。
- 预检、短链解析与扫描共用 SQLite 里的请求预算；预检失败也持久保存退避，换链接或重开页面不能重置等待。代价：快速完成绑定后可能要等一会儿才能建基线；页面显示等待时间，不提供绕过入口。
- 显式 sync 独立于自动模式：只扫描一次并冻结本次待发集合，并发请求在事务内合并；本次队列投递间隔默认 10 秒。

## 状态与控制
- 页面与 agent 共用 Control；模式与间隔存 SQLite meta，优先于配置默认值。worker 每 2 秒查看控制，当前一条完成后应用变化，无需重启。
- 控制状态和投递诊断都用已有 schema v1 的 meta 扩展，不新增业务表；升级沿用旧去重记录。回滚旧版前停止全部 worker 并备份 SQLite。
- 候选收藏夹通过预检才提交归属；配置写入异常时 Store 回滚归属与暂停变化。已有历史/任务时禁止换源。

## 部署向导与安全
- 四步本地网页向导，静态 HTML/CSS/JS 随 wheel 分发，标准库 HTTP 服务只监听 127.0.0.1；不需要前端构建或 Node。代价：暂不支持远程浏览器管理。
- AppSecret 经页面验证后保存到系统凭据库，配置只存随机引用；保留无桌面环境的显式环境变量入口，没有明文后备。代价：Linux 需要可用的 Secret Service，换机器要重新提供密钥。
- 设置 API 校验会话令牌、精确 Host/Origin，限制请求体与频率；令牌放在 URL fragment，浏览器读取后立即从地址栏移除。同标签页换成新的完整链接会自动重载恢复。
- 首次读取设置失败时显示错误和完整链接的恢复指引，不通过匿名状态接口绕过会话鉴权。
- 群绑定与首次基线完成后，由用户显式启用转发，默认建议手动模式。

## 后台进程
- start 以独立会话启动 worker，PID/会话标识、进程锁和心跳共同确认启动；stop 使用会话专属的协作停止标记。暂不安装开机服务；下载/上传中的停止要等当前一条结束。
- 锁文件首字节只用于系统排他锁，读取持有者从第二字节开始（Windows 会锁住首字节）。启动端生成随机会话标识经子进程环境传给 worker，不要求虚拟环境启动器 PID 等于 worker PID。
- 停止请求已接受而进程尚未退出时，页面显示“正在停止”，不再承诺自动重试或继续处理。
