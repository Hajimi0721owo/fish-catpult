# 验证状态（0.1 开发版）

本项目目前是开发版：主链路有真实平台实测，部署向导与后台控制有完整离线测试，跨平台和长期无人值守仍在验证中。下面只列当前版本的结论。

## 自己跑测试

```sh
PYTHONPATH=src python -m unittest discover -s tests -v   # 90 项，离线，不访问 B 站/QQ
node --test tests/test_ui_lines.mjs                      # 可选：设置页台词回归，需要 Node.js
PYTHONPATH=src:tests python tests/browser_setup.py        # 可选：完整向导浏览器流程，需要 Playwright
```

测试全部使用临时目录、虚构凭据和模拟的收藏夹/QQ 适配器。普通安装和运行不依赖 Node.js 或 Playwright。

## 已离线验证

- 首次基线、BV 永久去重、SQLite 队列、重启续传、缺回执记为 uncertain 且不自动重发。
- 四步网页向导：收藏夹预检（分享文本、b23.tv 短链、手机链接）、机器人凭证、群口令绑定、基线与显式启用；手机宽度无横向滚动，深色模式可用。
- 设置服务只监听回环地址，校验会话令牌、Host/Origin，限制请求体与频率；静态资源白名单，拒绝路径穿越。
- 后台 start/stop 的真实双进程握手、协作停止、防重复启动；schedule / sync / sync --cancel 的合并与冷却。
- AppSecret 存进系统凭据库，配置文件只保存引用：macOS 钥匙串读写删除通过；Windows 识别到凭据管理器后端（WinVaultKeyring），读写未单独实测。
- Windows + Python 3.14.5：锁文件读取、虚拟环境启动器 PID 与 worker 不同时的启动握手均已修复并通过当时的测试。

## 还没验证

1. 新用户从零申请机器人、绑定群的完整真实流程；群内视频播放画质。
2. 干净系统上的安装：Linux（Secret Service）、Windows 凭据管理器读写及最新提交的复测、不同 FFmpeg 版本。
3. 跨多个真实轮询周期的长期无人值守运行。
4. B 站私密收藏夹、b23.tv 收藏夹短链、QQ 11298（IP 白名单）的真实返回值；目前按已知错误码映射，其余走通用说明。

## 已知问题

- 没有开机自启；电脑重启后需要再启动一次（`start`，或对 agent 说“启动投石机”）。
